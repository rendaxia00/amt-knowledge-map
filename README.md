# AMT 知识地图

Cloud9 AMT 课程的中文网页学习地图：将 38 个章节组织成 **市场语境 → 价值位置 → 订单流触发 → 执行风控 → 复盘进化** 五个阶段，并为每章提供核心知识点、练习清单、常见误区、关键词和关联章节。

## 内容来源

- 已读取并整理 `E:\订单流课程\cloud\AMT` 中 37 份英文 `en.srt` 字幕。
- 第 15 章只有视频、没有英文字幕，页面内已明确标注为“仅依据标题提炼”。
- 本站是学习笔记与知识重组，不构成交易建议。

## 功能

- 交互式课程知识地图
- 章节索引与中英文标题
- 术语、章节和知识点全文搜索（按 `/` 快速聚焦）
- 每章详细解释、练习和误区
- 本地学习进度记录
- 桌面与移动端响应式布局

## 本地运行

这是零构建静态站点。可直接打开 `index.html`，或用任意静态服务器运行：

```bash
npx serve .
```

## 文件

- `index.html`：页面结构
- `styles.css`：Auction Cartography 视觉系统与响应式布局
- `data.js`：38 章中文知识内容与术语表
- `app.js`：地图、搜索、章节导航和本地进度交互
